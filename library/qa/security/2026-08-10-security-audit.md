## High Findings (fixed in this session)

- [x] **Secret exposure in error logging** `src/routes/api.lead.ts:84` - The outbound `fetch` catch previously logged the raw error object, which can include the destination URL. The handler now logs only a static message and never emits the GHL webhook URL or submitted lead data.

## Medium Findings (follow-up required)

- [ ] **Public endpoint abuse protection** `src/routes/api.lead.ts:43` - The route is intentionally public and now enforces strict schema validation and a 16 KiB body limit, but it has no durable per-IP rate limit or bot challenge. Add a Cloudflare or Lovable rate limit and Turnstile before increasing paid traffic.
- [ ] **Content Security Policy** `src/server.ts:12` - HSTS, nosniff, frame denial, referrer policy, and permissions policy are now applied globally. A nonce-based CSP still needs a browser compatibility pass because this site currently uses inline styles and framework-injected scripts.
