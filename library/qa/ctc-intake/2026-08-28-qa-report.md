## Critical Issues (must fix)

- [ ] **Ben's consent text identifies Ahoo** - `src/components/site/HomeValueForm.tsx:4-5`

  `/avm-ben` renders this shared form with `assignedLo="Ben Mokri"`, but the TCPA consent presented to the borrower identifies "CTC Equity / Ahoo Khalessi". That is incorrect on Ben's dedicated path and the same text is submitted as the consent record. Suggested: derive the consent text from the assigned officer, defaulting to Ahoo only for shared and Ahoo routes.

  ```tsx
  const CONSENT_TEXT =
    "I agree to be contacted by CTC Equity / Ahoo Khalessi ...";
  ```

- [ ] **Ben's failed submission points borrowers to Ahoo's phone** - `src/components/site/HomeValueForm.tsx:130-133`

  A normal downstream failure on `/avm-ben` tells the borrower to call Ahoo's number. Suggested: pass the officer callback number into the form and use it in the error message.

  ```tsx
  } catch {
    setSubmitting(false);
    setError("We couldn't send your request yet. Please try again or call (949) 877-7234.");
  }
  ```

- [ ] **Ben's successful submission says Ahoo will respond** - `src/components/site/HomeValueForm.tsx:151-156`

  After a successful `/avm-ben` submission, the confirmation says Ahoo will prepare the report. This contradicts the dedicated Ben workflow and the page promise that Ben handles the request. Suggested: render the assigned officer's first name, with the shared route retaining the existing Ahoo-and-team wording.

  ```tsx
  <p style={{ color: "var(--muted-ink)" }}>
    Ahoo and the CTC Equity team will prepare your free home value report and reach out
    shortly with your numbers.
  </p>
  ```
